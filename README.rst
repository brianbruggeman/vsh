==========================
vsh — Python environments
==========================

``vsh`` creates, lists, enters, and removes Python virtual environments. The
command line and Python API use the same Rust implementation.

Install vsh 0.8.0 after its release is available on PyPI::

    python -m pip install vsh==0.8.0

Python 3.9 or newer is required. Read the `Using vsh guide`_ for installation,
configuration, command examples, and the Python API.

.. _Using vsh guide: https://github.com/brianbruggeman/vsh/blob/main/docs/using-vsh.md
