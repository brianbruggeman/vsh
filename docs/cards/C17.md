## Design evidence

`PyConfig` and `PyCreateOptions` are PyO3 ABI boundary types; each holds the
existing validated Rust value rather than duplicating configuration state.
`VshError` and `VshConfigError` are required Python exception types. Config
file I/O delegates to the existing `LoadConfigPipe` and `StoreConfigPipe`.

## Postmortem

The first Python test run imported the legacy top-level `vsh/` package because
the working directory shadowed the new mixed-package wheel. Inspection of
`vsh.__file__` exposed the collision. Run wheel tests from outside the source
repository with the installed wheel first on `PYTHONPATH`; the corrected final
run imported the wheel and passed. Maturin also copied a built extension into
the source package during wheel construction; remove that generated binary
before staging, and keep validation artifacts outside the repository.
