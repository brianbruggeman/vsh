## Design evidence

`ShellPipe` is one zero-sized Proxima adapter with input
`(Config, Vec<OsString>, Vec<(OsString, OsString)>)`, output
`std::process::Output`, and `conflaguration::Error`. The argument vector is
already tokenized by the caller, so this layer does no shell-string quoting.
Environment resolution remains with the caller; the pipe clears ambient
variables and applies only supplied entries and the venv markers. No additional
state struct or lock is introduced. Process creation and captured output are
OS effects, so this pipe is an effect boundary rather than a claimed zero-copy
path.
