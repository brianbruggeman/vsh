## Design evidence

The `CliAction` enum represents mutually exclusive commands and carries their
unparsed OS argument vectors. It is the only new data type. Four zero-sized
pipes have different signatures for parsing, help text, command listing, and
prefix completion. The environment `list` command is recognized but awaits
config/effect wiring in C16. No global config is read or resolved in this card;
C15 owns that boundary.
