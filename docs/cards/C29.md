# C29 — Flush child output from the installed console

## Acceptance

- Preserve exact child stdout and stderr bytes, including streams that do not end in a newline, when the shared Rust CLI is invoked through the installed PyO3 console entrypoint.
- Add native installed-wheel regression cases for no-newline stdout and stderr plus existing newline behavior; assert exact bytes and exit status, and report nonzero test count.
- Run the installed-wheel gate on native Linux, macOS, and Windows; independent code↔card and tests↔card reviews; postmortem; promote only green.

## Evidence

C25 exact-wheel reproduction: installed `vsh enter ... --shell /bin/sh -- -c 'printf abc'` exits 0 but captures empty stdout. `printf 'abc\n'` and `echo abc` capture their text and newline. Direct Rust binary invocation preserves the bytes, localizing the loss to the Python console process path. Hypothesis: the embedded Rust stdout writer needs an explicit flush before the Python entrypoint returns; prove with the regression test and a one-variable fix.

## Postmortem (draft)

The C25 exact-wheel guide gate caught a missing newline in child stdout before release. The first focused installed-wheel test made the regression concrete: status 23 and stderr bytes were preserved, newline-terminated stdout/stderr were exact, but no-newline stdout was empty. Adding explicit flushes at the stdio effect boundary changed the no-newline stdout result from empty to exact bytes while preserving stderr, newline behavior, and status. `WriteOutputPipe` gives that effect a typed Proxima boundary and propagates write/flush errors instead of discarding them; it writes from the captured buffers without copying. The red/green regression proves that explicit flush at the installed stdio boundary fixes the observed output-loss behavior. The new private pipe is justified as the process-bound stdio sink (`In=Output`, `Out=i32`, `Err=conflaguration::Error`); no existing Proxima primitive targets global process stdout/stderr, and making it private avoids expanding the library API. A helper could return `Result` too; the pipe keeps the final stdio effect explicit and typed in the CLI flow without adding public API. Safe Rust's process stdout/stderr streams use their standard per-stream synchronization; this introduces no application-owned shared-state lock, and holding each guard across write plus flush avoids reacquiring it between those operations. The installed-wheel test now covers both streams and statuses on newline and no-newline cases. The initial local gate invocation lacked `maturin` on PATH; using the documented `uv run --no-project --with maturin --with packaging` invocation fixed the harness setup. Correction for future child-process features: exercise the installed entrypoint and compare captured bytes, status, and cleanup, including no-newline streams, on native platforms.
