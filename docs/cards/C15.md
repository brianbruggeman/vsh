## Design evidence

The existing library `Config` is already `#[derive(Settings)]`, serializable,
and validated. `ParseConfigFlagsPipe` outputs the optional file path and a
vector of `(field name, OsString)` overrides. `ResolveConfigPipe` uses the
conflaguration builder in documented precedence order: `.value(default)`,
optional `.file`, `.env`, `override_with` for flags, `.validate().build()`. No
second config struct or parser dependency is added. Pipe composition connects
the two stages with matching error types.
