## Implementation notes

On Windows, `std::process::Command::args` applies standard CRT argument
escaping, which `cmd.exe /C` does not parse as standard argv. The first native
run exposed literal backslash-quote characters in `cmd.exe` output. The Windows
`cmd.exe /C` path now uses `CommandExt::raw_arg` for an outer-quoted command
tail, matching Rust's documented `cmd.exe` invocation pattern. Other shells and
non-Windows behavior continue to use normal argument encoding. The `ShellPipe`
input is shell syntax rather than a safe `argv` boundary; for `cmd.exe /C`,
multiple post-`/C` values are joined as one command string. Callers must not use
this interface to interpolate untrusted data into a command.

Native run 38608870165 on commit `1c9f6fa51d94022e6b139aee772e0c9a57a93190`
compiled on Windows Server 2025 and ran exactly one selected test; it failed
because the output contained literal `\\\"` around the cwd. This failed
checkpoint was kept on the card branch only and will be amended before landing.

The corrected commit `b8534d99d7c0055b21372c9022e048c448302ce6` passed native
run [38609562636](https://github.com/brianbruggeman/vsh/actions/runs/38609562636)
on Windows Server 2025. The exact gated test ran once and passed; the gate
reported `GREEN C21`, exit 0, passed 1, failed 0.

## Postmortem

The existing Windows-only test and CI step were useful starting points, but
ordinary Rust Windows argument quoting did not match `cmd.exe /C` parsing. The
first native run caught literal backslash-quote output. The fix uses the
documented raw command tail only for Windows `cmd.exe /C`; the card now states
that this input is shell source rather than a safe data argument boundary.
The exact-test `card_gate.py` step prevented generic Unix tests from masking a
zero-test Windows selection. For the next platform card, define the OS-specific
command contract before implementation, make its CI select only the relevant
native test, and preserve the first failed native result as evidence while
fixing the card branch before main promotion.
