## Design evidence

The host CLI/library has a std build script, while the generated value is a
plain `usize` constant available to lower tiers. The conflaguration 2.0.0
`ConfigCodegen` derive is used instead of manually formatting a Rust source
file. `VSH_MAX_WALK_DEPTH` and its default `32` occur only in the build config;
the library exports the generated field. `rerun_for` derives Cargo's env
invalidation key from the Settings type. The build script also exports its
resolved scalar through Cargo's build env so the test can compare the generated
constant against the exact build-time input, including override builds.

## Postmortem

The first evidence check compared the generated constant only with a value
emitted by the same build script. That would not catch an ignored override.
Use an isolated target, set a non-default value, and compare the generated
constant and build output to the requested number itself. This card records
that exact check and its artifact lines.
